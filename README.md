# Games Hub · 游戏合集

十五个休闲小游戏的合集单页应用：首页选择游戏，游戏内点 🏠 随时返回。

| 游戏 | 玩法简介 |
| --- | --- |
| 👆 点击游戏 | 点击方块使自身与上下左右数字 +1（逢 3 归 0），在限定步数内把全部数字归零；另有**⚡ 上帝模式**（刚开局、还没手动点过时可用）自动完成最优解，**播放中再点一下按钮即可暂停 —— 暂停就是把操作权交回给你**（遮罩撤掉、可以接着手动点或撤销），把所有操作撤销回初始局后可以再点它重跑 |
| 🧩 数字迷宫 | 经典数字华容道：点击或摇杆/方向键滑动，把数字按顺序排列 |
| 🔢 1A2B | 8 次机会猜一个不重复数字的 4 位数，根据 xAxB 提示逼近答案 |
| 🃏 德州扑克 | 单人视频扑克：下注 → 发牌 → 选牌保留 → 换牌，中牌型可继续猜大小翻倍 |
| 3️⃣ Threes | 1 + 2 = 3 的经典合成：滑动合并相同数字，牌堆预告下一张牌；新牌固定从「滑动来源侧」边缘补进，盘面上 1 与 2 的个数差不超过 4。在页面任意位置（不只是棋盘上）按住拖动都能滑，滑动是**跟手**的：手指按住拖动时，这一步会动的牌实时跟着位移（不足一格时正好压在目标牌上，形成重叠覆盖的手感）。盖到目标牌一半以上再松手才合并，不到一半松手就弹回原格；盖到 95% 时不等松手就直接合并 |
| 🔢 2048 | 经典 2048：滑动合并相同数字，凑出 2048 获胜，之后可继续冲击高分 |
| 🐍 贪吃蛇 | 方向键 / 滑屏控制蛇吃食物，1-5 级难度，难度越高速度越快、单食物得分越高；可以暂停（切后台会自动暂停），**点继续后先倒数 3 2 1 再恢复** |
| 😊 Emoji 对对碰 | 记忆翻牌**闯关**：每关先全体亮牌观察 4~14 秒（牌越多越久），然后翻面并开始限时倒计时（**观察与倒计时就显示在「新游戏」左边**），限时内清空全部牌过关；时间到则失败，**并把没消掉的牌全部翻到正面**摊牌。关卡越高棋盘越大 —— emoji `2×3` 一路到 `6×8`、扑克 `2×3` 到 `6×7`（第 11 关封顶、关数无限），限时按「对数 × 每对 4~5.2 秒 + 4 秒」给；连续配对不翻错会累计**连击**并放小烟花。右上角帮助旁可以**切换牌面**：emoji ↔ 扑克牌（2:3 长方形牌，直接复用扑克游戏的牌面），两套牌面的当前关卡与最高关卡**各自独立保存**；**只有分出胜负的结算会被记住**（重进或切牌面都停在结算浮层，自己点「下一关 / 重玩本关」）；一关还没打完就退出或切牌面，则**重开本关**，「新游戏」二次确认后只把当前牌面从第 1 关重开 |
| 🔗 Emoji 连连看 | 闯关制连连看：限定时间内清空全盘过关；列数 6→10、行数 6→12、emoji 种类、牌数、墙数（0→18）与限时共同决定难度，第 30 关到顶但关数无限；同一种 emoji 可出现多对。**连击**：两次消除之间没有无效点击、且间隔在 2.5 秒内就累积连击，棋盘上方弹出「N 连击」并放一束快速烟花（连得越高字越大、烟花越大）；间隔超过 2.5 秒，或点到的牌没被消掉（emoji 不同 / 连线不通 / 取消选择），连击中断 |
| 🕵️ Emoji 侦探 | 找茬记忆挑战：记住一组牌，翻面后找出被偷换的那一个，关卡逐步加难；顶部统计卡中间显示**当前第几关**；「新游戏」会先弹二次确认（确认后清记录、回第 1 关）。**答对之后先停留 0.5 秒**（答对的牌当场亮绿并弹一下、扩散一圈光环），再弹过关浮层；**扣掉最后一颗心时不立刻铺失败遮罩**：先等点错那张的抖动放完，再在**被偷换的那张上盖一个歪的「✓ 正确」章**（像盖章一样落下来），随后这张牌震一下，最后才出失败遮罩与结算（答错的那几张仍标红）。整个过程约 1.5 秒，让玩家看清答案是哪张；停留期间不能操作。答错一次扣一条命，而且**点错的牌会红色标记、不能再点**（同一张最多只扣一颗心）（右上角一行 ❤️，失去的那颗会先放大淡出再变成 🤍）。右上角帮助旁可以**切换牌面**：emoji ↔ 扑克牌（牌面直接复用扑克游戏的牌，长方形 2:3，所以排列按列多行少来适应宽高比）。玩法两套完全一样，但扑克牌有花色 + 点数两层线索更好记，所以牌数更多（1×4 → 4×7 共十关，emoji 是 1×3 → 4×5 共九关）；两种牌面的关卡进度、最高关卡与当前局面**各自独立存档**，切回来接着上次继续 |
| 🎯 Emoji 猎手 | 记忆收集挑战：记住目标 emoji，翻面后从候选区把它们全部找回；顶部统计卡中间显示**当前第几关**；「新游戏」会先弹二次确认（确认后清记录、回第 1 关）。找回的候选会**弹一下并扩散一圈绿光环**，选错候选会**当场抖一下并标红**（与 Emoji 侦探同款）、扣一条命（右上角一行 ❤️，失去的那颗会先放大淡出再变成 🤍）。观察时长随关卡放宽（3 秒起、第 3 关起每关 +0.4 秒，第 6 关 4.2 秒）。每关开始时展示区的目标牌一律从**背面**翻到正面（候选区同时整体扣在背面，中途不会先闪一下新 emoji），记忆结束后候选区再整体从背面翻正让玩家作答。右上角帮助旁可以**切换牌面**：emoji ↔ 扑克牌（牌面直接复用扑克游戏的牌，2:3 长方形，所以目标更多、候选区更宽：最多 9 个目标 / 4×8）。玩法完全一样，两套牌面的关卡进度与当前局面**各自独立保存** |
| ⭐ Emoji 消消乐 | 闯关制三消：限定步数内达到目标分过关（无计时器）；面板从 7×7 长到 9×10，emoji 种类从 4 种长到 6 种（步数 22 → 20、目标分 1500 → 3000、墙 0 → 8），带 💣 炸弹（相邻消除即引爆、炸掉周围 3×3 并震动棋盘）、💎 万能元素（可当任意 emoji 参与连线）与 🧱 不可消除的墙（emoji 可穿过下落）、❄️ **冰块**（冻住的 emoji 不能消除也不能交换，消掉相邻的格子即解冻（冰层会裂开、碎冰四散）；永远连成一片出现，随关卡从 0 块涨到 8 块（第 30 关），之后每 2 关再 +1、最多 14 块），操作区会显示本关墙数；第 30 关面板 / 种类 / 墙 / 特殊元素到顶，之后每关 **+1 步、目标分 +230** 继续线性加码，难度不会早早固定。计分以基础消除为主（三连 60 分、每多消一个 +35；连锁每层 +30%、最多翻倍；炸弹每格 12 分），离线模拟（贪心挑最大三连）下第 30 关中位分约 3900 对目标 3000、过关率约 8 成（冰块因为邻格一消就化、对贪心玩家几乎无影响，对人则要花心思先化冰）；6 秒没有操作会提示一对可消除的 emoji（该交换的两个 emoji 大幅呼吸三下，牌面底色同时脉冲发光，每次换一对）；一轮消掉 4 个以上或连成连锁时庆祝：棋盘外圈闪光、中央弹出「连消 / 连锁 + 本次得分」并撒花（两者同时达成时两行文案上下分开显示），一轮 ≥4 个的那批牌还会爆得更大 |
| 🗾 数独 | 唯一解挖洞生成，填错即标红并扣 ❤️ 生命（三档难度各带 1 / 2 / 3 颗 ❤️，扣掉最后一颗的那次即失败，也就是简单错一次、中等两次、困难三次），支持笔记候选（手动逐个标记）与**候选**一键填空（激活后点空白格，自动填入该格所有可用候选 = 排除同行、同列、同宫后剩下的数；两者互斥）；右上角还有**候选按钮行为开关**：开启后按一下「候选」就直接把所有空白格一次填满；点盘面上任意一个数字，会同时高亮所有同数字的格子和其它空格里相同的候选数字（候选数字直接给**底色块**，同数字格、同行列宫格、选中格是三档由浅到深的高亮，被高亮的格子里数字统一用实心字色，避免绿压绿看不清）；**填对一个数字后，会把它从同行、同列、同宫其它空格的候选里自动划掉**（填错则不动）。记录各难度最佳用时 |
| ⬇️ Emoji 下坠 | 反应类街机玩法：8 行 × 6 列的棋盘上，整排 emoji 从底部不断升起、把上面的排往上顶；你控制骑在整摞最上方的那一个 emoji，点任意一列它就**滑过去**（带滑动动画）——停在「顶层这一列的 emoji 跟自己相同」的位置，那**一整排就炸开消失**，你的 emoji 落到下一排上方，消一排得一分。每一排都保证 5 种齐全，所以目标永远存在，比的就是在牌堆顶上来之前找到它；每消掉一排手里的 emoji 都有机会换一种——**第一次就有 25% 概率换，连续没换的排数越多越容易换，平均约 3.4 排换一次**（换来的一定是当前顶排里有的、且跟原来不同），每消一排上升速度还会再快一点，**到基础速度的 3 倍（1.05 行/秒）就封顶、之后不再加快**，emoji 被顶到棋盘顶部即失败。操作区是「计时 | 新游戏 | **暂停**」：可以主动暂停，切后台或离开界面也会**自动暂停**，重进时停在暂停态由你自己点「继续」，而点继续后会先在盘面上**倒数 3 2 1** 再恢复（贪吃蛇同样如此）。局中局面与失败结算都存档，结算层上点「新游戏」重开 |
| 🧩 Emoji 滑行 | 棋盘腾挪消除：整块棋盘上每种 emoji 都成对出现。**点**一个——上下左右有同款就把这两个炸掉；周围没有同款时，棋盘上所有同款一起晃动告诉你它们在哪。也可以**按住拖**：它会带着这个方向上**紧挨着它的那一段连续 emoji** 一起滑动（空格会断开，空格后面的不跟着走），能滑多远取决于前面有多少空格，所以先消掉几对、空出来的格子就是滑行的通道。松手时看你按住的那个落在哪：紧挨同款就消掉这一对、其它 emoji 留在滑过去的位置；没有同款则整组弹回原位（棋盘一格都不会变）。万一走到怎么挪都消不掉的地步，棋盘会自动重排剩下的 emoji（先只换种类，实在不行就把一对同款挪到同一行/同一列），保证重排后一定有得消——包括只剩最后一对、而且两张既不同行也不同列的情况。目标是在计时结束前清空整个棋盘；关卡越高棋盘越大、种类越多、时间越紧，且是**线性**爬升：第 1 关 6×6 · 5 种 · 99 秒（每对 5.5 秒），第 15 关到顶 11×8 · 7 种 · 176 秒（每对 4 秒），之后每关限时再收 3 秒、160 秒保底。**连击**：两次消除之间没有无效操作（滑动没消掉 / 点了但没同款都算）且间隔 < 2.5 秒就算连上，棋盘上方弹出「N 连击」并放一束小烟花（连得越高字越大、粒子越多），间隔超时或出现无效操作即中断。局中局面与结算都存档，重进接着玩 |
| 🔬 Emoji 排序 | 水排序式闯关玩法（标题栏帮助图标旁可切换两种玩法）：槽里的水果只有最上面那张是正面朝上的；点一下槽位，它槽口那一摞同种水果会整摞抬到槽口上方、像牌堆一样叠起来（每张盖住下面那张约 85% 的面积，最上面那张完整可见；再点一次就放回去），点另一个槽位则先在上方的空白带里平移过去、再从目标槽正上方落进去；**如果抬起的那一摞只有一个槽放得下，它会直接自动搬过去落下、搬运途中目标槽的高亮也会一直亮着，不用再点第二下**（有多个目标时仍由你选）（目标装不下时只搬得下的那几张，剩下的落回原槽），落定之后下面那张才自动翻面。难度由每种水果的张数 C 与种类 K 交替爬升，每 2~4 关抬一档，从 3 种×3 张涨到第 30 关的 6 种×8 张（48 张）；把每个槽都理成同一种水果、并让所有水果都翻成正面即过关；每一局的牌都先用求解器验证过有解才发出来，每走一步还会判一次——只有「还有水果扣着、却再也翻不开新牌了」或者「全翻开后已经怎么排都排不出来」才判失败（只要还翻得开就不会判负）。**失败演出**：判负时先等刚翻开那张的翻面动画播完，停 0.5s，然后六个槽从左到右挨个把整摞水果抬起一格再落下（像整盘牌一起叹口气），全部落定才弹出失败浮层，这段演出期间不响应任何操作；失败后可以在结算浮层上「重玩本关」。两种玩法共用这条曲线：**经典**每种水果刚好装满一槽，左右两侧各留 1 个空槽；**紧凑**只在最右侧留 1 个空槽，但每个槽开局都空出最上面一格当腾挪空间。两种玩法的关卡进度与局面存档各自独立，「新游戏」只清当前玩法 |
| 🧱 Emoji 大师 | 羊了个羊闯关玩法：点击未被遮挡的顶层卡片落入 7 格收集槽，凑齐 3 张相同 emoji 自动消除；被压住的卡片**一律不透明**（不按层数变透明，压得再深也只看得到从上层卡片边缘漏出来的那一角，想确认下面是什么就得先把它翻开），只靠变暗表示暂时不可点，游戏区是一张带底色的卡片；**卡片是立体的**（正面 + 底部一条厚度 + 落地阴影，像从正面偏下方斜着看过去，飞入暂存区后与飞行卡像素级对齐、交接不闪）；关卡越高层数与 emoji 种类越多（2 层 7 种 → 8 层 18 种，第 50 关到顶），同一种 emoji 可以出现多组（张数恒为 3 的倍数），无计时器、无洗牌，失败可重玩本关 |
| 🧪 扑克炼金术 | 4×4 棋盘上的扑克炼金（标题栏帮助图标旁可切换**闯关 / 无尽**两种模式）：手里一次只有一张牌、面板上还能看到接下来的两张（逐张小一号），点空格放入或把牌拖进空格 —— **点空白时那张牌会从手牌位置飞到目标格**，拖拽则跟手。凑满一整行 / 一整列 / 一整条对角线（共 10 条线）且这 4 张能组成牌型时，该线**先闪烁两下再整条消失**并计分 —— 四条 1000、同花顺 1000、三条 500、顺子 300、同花 200、两对 100、一对 50（凑不出牌型的线不消、留在盘上占格）。**一次落子同时凑成横 / 竖 / 斜多条线时只算分数最高的那条**，只有最高分并列才一起消除并累加分数，分数低的那几条原样留在盘上。牌堆里混有 **Joker**（按德州扑克的规矩渲染：黑 Joker 当 ♠、红 Joker 当 ♥）：**黑色的只能当 ♠/♣、红色的只能当 ♥/♦**，所以一黑一红两张永远凑不出同花；两种 Joker 各只有一张，**棋盘上也不会出现两张一模一样的牌**（发牌器按 52 张的牌靴抽、避开场上已有的牌）。**每次得分**都会在棋盘中央弹出「牌型名 + 本次得分」（照消消乐那一套，按分数分档放大），得分满 **300** 还会让棋盘震动、外圈闪光并撒花（低于 300 只有浮字）；过关 / 失败浮层会等这条提示露一下脸（0.5 秒）后再出现，过关本身用共用的那份大撒花。闯关模式第 1 关 24 张牌 / 800 分，每关 +1 张牌、过关分 +50、每 10 的倍数关再多 +100，在牌堆用完前达到目标分过关，无尽模式牌堆无限、直到 16 格全部放满才结束（「新游戏」只清已用牌数与当前得分、**保留最高分**），统计条随模式变化 —— 闯关四格「**关卡 / 剩余 / 得分 / 目标**」、无尽三格「**最高分 / 已用牌数 / 得分**」，两种模式各自独立记录  开局与**恢复记录**都从左上到右下逐张铺开（波浪），落子 / 消除各有动画。|

## 功能特性

- 🎨 深 / 浅色主题切换，全站共享
- 🌐 中 / 英双语切换，全站共享（帮助弹窗、界面文案全覆盖）
- 🏠 游戏标题栏一键返回主页
- 🎮 首页标题栏居中显示游戏图标（favicon 同款图案的矢量源文件），不再显示「游戏合集」文案；游戏内标题栏照旧显示各游戏名称
- 📱 移动端优先布局 + PWA，可安装到桌面 / 主屏幕，离线可玩（`workbox.globPatterns` 已带上图片类型，
  麻将牌雪碧图与各图标都进预缓存，断网时牌面也照常显示）
- 💾 各游戏的进度、局面存档、最佳成绩、偏好设置独立存储，互不干扰
- 🏁 五个闯关 emoji 游戏（连连看 / 消消乐 / Emoji 大师 / Emoji 猎手 / Emoji 侦探）**以及贪吃蛇**连**结算层**也会存档：过关**或失败**后退出重进还是那个结算层（盘面、得分与用时都停在结算那一刻），由玩家自己决定点「下一关」还是「重玩本关 / 新游戏」，既不会一进来就被自动推进到下一关，也不会莫名丢掉刚打完的那一局
- 🎇 全站粒子连线动态背景：固定置底、跟随鼠标 / 触摸（粒子轻微被排斥），按浅 / 深主题自动换色
- ✨ 开局与恢复存档时棋盘逐张入场：2048 / Threes / 消消乐逐张弹出、数独逐格浮现、Emoji 大师自下层向上堆叠、Emoji 排序按槽自下而上堆起来
- 🎉 消消乐的即时庆祝：一轮消掉 4 个以上、或连成连锁（≥2 层）时棋盘外圈闪光、中央弹出「N 连消 / N 连锁」与本次得分（两者同时达成时分成上下两行）、并撒一把花，两者同时达成时浮字与光圈最大（`shared/confetti.js` 新增的 `burstConfetti`，与过关撒花同一套配色，只是原地炸一次）
- 📊 八个闯关游戏（连连看 / 消消乐 / Emoji 大师 / Emoji 排序 / Emoji 滑行 / 扑克炼金术 / 麻将英雄 / 雀圣）顶部卡片底部有本关进度条，操作区另一半显示本关盘面信息（连连看 / 消消乐：尺寸 · 种类 · 墙数，Emoji 大师：层数 · 种类，Emoji 排序：槽位 · 每槽层数 · 种类），并且只放「新游戏」按钮（点开的是这几个游戏共用的同一个二次确认弹窗，弹窗里除了「确定重来」还有「重玩本关」——只重开当前这一关、保留闯关进度 `shared/ConfirmDialog.vue`，确认后清记录、从第 1 关重来），失败时在结算浮层上「重玩本关」
- 🔹 各 emoji 游戏（对对碰 / 连连看 / 侦探 / 猎手 / 消消乐 / 大师 / 排序）的游戏区都带一层很淡的点阵底纹，牌消掉后不至于一片空白
- 🎨 这七个 emoji 游戏共用一套视觉参数：棋子/牌面圆角与描边、软阴影、牌背用各自在首页的图标、面板与统计条尺寸、按钮样式、结算浮层的间距与字号（浮层用 box-sizing: border-box，尺寸正好贴合棋盘）
- 🖐️ 首页卡片支持拖动排序，顺序记在本地；新增游戏自动接在已排序结果之后
- 🥚 彩蛋：在有成绩记录的游戏（点击 / 迷宫 / 对对碰 / 连连看 / 侦探 / 猎手 / 消消乐 / 数独 / 排序）中连点标题 5 次清除历史记录

## 技术栈

- Vue 3（Composition API + `<script setup>`）+ Vue Router
- Vite 5
- UnoCSS（attributify + icons：carbon / mdi）
- SCSS
- vite-plugin-pwa
- canvas-confetti

## 快速开始

```bash
yarn install
yarn dev       # 启动开发服务器
yarn build     # 构建到 dist/
yarn preview   # 本地预览构建产物
```

> 本目录的 `.yarnrc` 已将 registry 覆盖为 npm 官方源；若你的全局 yarn 指向内网镜像，无需修改即可正常安装。

## 目录结构

```
src/
├── App.vue          # 根组件 + 全局主题 CSS 变量（浅/深两套）
├── router.js        # hash 路由：/ /click /puzzle /guess /poker /three /2048 /snake /match /link /detective /hunter /crush /sudoku /master /sort /down /slide /alchemy /mahjong /quesheng
├── shared/          # 共享模块：i18n（多语言）、theme（主题）、games（游戏注册表）、emojis（emoji 池）
├── components/      # HomePage（首页）、TopHeader（标题栏）、HelpDialog（帮助弹窗）
└── games/           # 二十个游戏源码，每游戏一个目录
    ├── click/  puzzle/  guess/  poker/  three/  g2048/  snake/
    └── match/  link/  detective/  hunter/  crush/  sudoku/  master/  sort/  down/  slide/  alchemy/  mahjong/  quesheng/
scripts/             # 图标源文件（SVG + 512px PNG）
public/              # favicon 与 PWA 图标
```

各游戏的完整说明与实现细节见 [AGENTS.md](./AGENTS.md)；本合集由同级的四个独立游戏项目（`click-game/`、`guess-number/`、`poker/`、`puzzle-game/`）合并而来。

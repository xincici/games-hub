# Games Hub · 游戏合集

十五个休闲小游戏的合集单页应用：首页选择游戏，游戏内点 🏠 随时返回。

| 游戏 | 玩法简介 |
| --- | --- |
| 👆 点击游戏 | 点击方块使自身与上下左右数字 +1（逢 3 归 0），在限定步数内把全部数字归零 |
| 🧩 数字迷宫 | 经典数字华容道：点击或摇杆/方向键滑动，把数字按顺序排列 |
| 🔢 1A2B | 8 次机会猜一个不重复数字的 4 位数，根据 xAxB 提示逼近答案 |
| 🃏 德州扑克 | 单人视频扑克：下注 → 发牌 → 选牌保留 → 换牌，中牌型可继续猜大小翻倍 |
| 3️⃣ Threes | 1 + 2 = 3 的经典合成：滑动合并相同数字，牌堆预告下一张牌；新牌固定从「滑动来源侧」边缘补进，盘面上 1 与 2 的个数差不超过 4 |
| 🔢 2048 | 经典 2048：滑动合并相同数字，凑出 2048 获胜，之后可继续冲击高分 |
| 🐍 贪吃蛇 | 方向键 / 滑屏控制蛇吃食物，1-5 级难度，难度越高速度越快、单食物得分越高 |
| 😊 Emoji 对对碰 | 记忆翻牌配对：预览后翻面（牌背用它在首页的那个图标），翻开两张相同的牌即消除，清空棋盘获胜。右上角帮助旁可以**切换牌面**：emoji ↔ 扑克牌（牌面直接复用扑克游戏的牌，2:3 长方形，所以棋盘改成横向排布、张数略少：4×4 / 5×6 / 6×8）。玩法完全一样，两套牌面的难度与最佳用时**各自独立保存** |
| 🔗 Emoji 连连看 | 闯关制连连看：限定时间内清空全盘过关；列数 6→10、行数 6→12、emoji 种类、牌数、墙数（0→18）与限时共同决定难度，第 30 关到顶但关数无限；同一种 emoji 可出现多对。**连击**：两次消除之间没有无效点击、且间隔在 2.5 秒内就累积连击，棋盘上方弹出「N 连击」并放一束快速烟花（连得越高字越大、烟花越大）；间隔超过 2.5 秒，或点到的牌没被消掉（emoji 不同 / 连线不通 / 取消选择），连击中断 |
| 🕵️ Emoji 侦探 | 找茬记忆挑战：记住一组牌，翻面后找出被偷换的那一个，关卡逐步加难；答错一次扣一条命，而且**点错的牌会红色标记、不能再点**（同一张最多只扣一颗心）（右上角一行 ❤️，失去的那颗会先放大淡出再变成 🤍）。右上角帮助旁可以**切换牌面**：emoji ↔ 扑克牌（牌面直接复用扑克游戏的牌，长方形 2:3，所以排列按列多行少来适应宽高比）。玩法两套完全一样，但扑克牌有花色 + 点数两层线索更好记，所以牌数更多（1×4 → 4×7 共十关，emoji 是 1×3 → 4×5 共九关）；两种牌面的关卡进度、最高关卡与当前局面**各自独立存档**，切回来接着上次继续 |
| 🎯 Emoji 猎手 | 记忆收集挑战：记住目标 emoji，翻面后从候选区把它们全部找回；选错候选扣一条命（右上角一行 ❤️，失去的那颗会先放大淡出再变成 🤍）。每关开始时展示区的目标牌一律从**背面**翻到正面（候选区同时整体扣在背面，中途不会先闪一下新 emoji），记忆结束后候选区再整体从背面翻正让玩家作答。右上角帮助旁可以**切换牌面**：emoji ↔ 扑克牌（牌面直接复用扑克游戏的牌，2:3 长方形，所以目标更多、候选区更宽：最多 9 个目标 / 4×8）。玩法完全一样，两套牌面的关卡进度与当前局面**各自独立保存** |
| ⭐ Emoji 消消乐 | 闯关制三消：限定步数内达到目标分过关（无计时器）；面板从 7×7 长到 9×10，带 💣 炸弹（相邻消除即引爆、炸掉周围 3×3 并震动棋盘）、💎 万能元素（可当任意 emoji 参与连线）与 🧱 不可消除的墙（emoji 可穿过下落），操作区会显示本关墙数；第 30 关面板 / 种类 / 墙 / 特殊元素到顶，之后每关 **+1 步、目标分 +160** 继续线性加码，难度不会早早固定。计分以基础消除为主（三连 60 分、每多消一个 +35；连锁每层 +30%、最多翻倍；炸弹每格 12 分），离线模拟下第 30 关基础消除占得分 53%、炸弹占 19%，过关不再依赖连锁与炸弹的运气；6 秒没有操作会提示一对可消除的 emoji（该交换的两个 emoji 大幅呼吸三下，牌面底色同时脉冲发光，每次换一对）；一轮消掉 4 个以上或连成连锁时庆祝：棋盘外圈闪光、中央弹出「连消 / 连锁 + 本次得分」并撒花（两者同时达成时两行文案上下分开显示），一轮 ≥4 个的那批牌还会爆得更大 |
| 🗾 数独 | 唯一解挖洞生成，填错即标红并扣 ❤️ 生命（三档难度各带 1 / 2 / 3 颗 ❤️，扣掉最后一颗的那次即失败，也就是简单错一次、中等两次、困难三次），支持笔记候选，记录各难度最佳用时 |
| ⬇️ Emoji 下坠 | 反应类街机玩法：8 行 × 6 列的棋盘上，整排 emoji 从底部不断升起、把上面的排往上顶；你控制骑在整摞最上方的那一个 emoji，点任意一列它就**滑过去**（带滑动动画）——停在「顶层这一列的 emoji 跟自己相同」的位置，那**一整排就炸开消失**，你的 emoji 落到下一排上方，消一排得一分。每一排都保证 5 种齐全，所以目标永远存在，比的就是在牌堆顶上来之前找到它；每消除 3~5 排手里的 emoji 会随机换一种（新的一定出现在当前顶排里），每消一排上升速度还会再快一点，emoji 被顶到棋盘顶部即失败。操作区显示本局**计时**（失败时停在最终用时），局中局面与失败结算都存档，重进接着玩、结算层上点「新游戏」重开 |
| 🔬 Emoji 排序 | 水排序式闯关玩法（标题栏帮助图标旁可切换两种玩法）：槽里的水果只有最上面那张是正面朝上的；点一下槽位，它槽口那一摞同种水果会整摞抬到槽口上方、像牌堆一样叠起来（每张盖住下面那张约 85% 的面积，最上面那张完整可见；再点一次就放回去），点另一个槽位则先在上方的空白带里平移过去、再从目标槽正上方落进去（目标装不下时只搬得下的那几张，剩下的落回原槽），落定之后下面那张才自动翻面。难度由每种水果的张数 C 与种类 K 交替爬升，每 2~4 关抬一档，从 3 种×3 张涨到第 30 关的 6 种×8 张（48 张）；把每个槽都理成同一种水果、并让所有水果都翻成正面即过关；每一局的牌都先用求解器验证过有解才发出来，每走一步还会判一次——只有「还有水果扣着、却再也翻不开新牌了」或者「全翻开后已经怎么排都排不出来」才判失败（只要还翻得开就不会判负）。**失败演出**：判负时先等刚翻开那张的翻面动画播完，停 0.5s，然后六个槽从左到右挨个把整摞水果抬起一格再落下（像整盘牌一起叹口气），全部落定才弹出失败浮层，这段演出期间不响应任何操作；失败后可以在结算浮层上「重玩本关」。两种玩法共用这条曲线：**经典**每种水果刚好装满一槽，左右两侧各留 1 个空槽；**紧凑**只在最右侧留 1 个空槽，但每个槽开局都空出最上面一格当腾挪空间。两种玩法的关卡进度与局面存档各自独立，「新游戏」只清当前玩法 |
| 🧱 Emoji 大师 | 羊了个羊闯关玩法：点击未被遮挡的顶层卡片落入 7 格收集槽，凑齐 3 张相同 emoji 自动消除；被压住的卡片按覆盖层数分档变淡（压得越深越透明），游戏区是一张带底色的卡片；关卡越高层数与 emoji 种类越多（2 层 6 种 → 8 层 16 种，第 50 关到顶），同一种 emoji 可以出现多组（张数恒为 3 的倍数），无计时器、无洗牌，失败可重玩本关 |

## 功能特性

- 🎨 深 / 浅色主题切换，全站共享
- 🌐 中 / 英双语切换，全站共享（帮助弹窗、界面文案全覆盖）
- 🏠 游戏标题栏一键返回主页
- 🎮 首页标题栏居中显示游戏图标（favicon 同款图案的矢量源文件），不再显示「游戏合集」文案；游戏内标题栏照旧显示各游戏名称
- 📱 移动端优先布局 + PWA，可安装到桌面 / 主屏幕，离线可玩
- 💾 各游戏的进度、局面存档、最佳成绩、偏好设置独立存储，互不干扰
- 🏁 五个闯关 emoji 游戏（连连看 / 消消乐 / Emoji 大师 / Emoji 猎手 / Emoji 侦探）连**结算层**也会存档：过关**或失败**后退出重进还是那个结算层（盘面、得分与用时都停在结算那一刻），由玩家自己决定点「下一关」还是「重玩本关 / 新游戏」，既不会一进来就被自动推进到下一关，也不会莫名丢掉刚打完的那一局
- 🎇 全站粒子连线动态背景：固定置底、跟随鼠标 / 触摸（粒子轻微被排斥），按浅 / 深主题自动换色
- ✨ 开局与恢复存档时棋盘逐张入场：2048 / Threes / 消消乐逐张弹出、数独逐格浮现、Emoji 大师自下层向上堆叠、Emoji 排序按槽自下而上堆起来
- 🎉 消消乐的即时庆祝：一轮消掉 4 个以上、或连成连锁（≥2 层）时棋盘外圈闪光、中央弹出「N 连消 / N 连锁」与本次得分（两者同时达成时分成上下两行）、并撒一把花，两者同时达成时浮字与光圈最大（`shared/confetti.js` 新增的 `burstConfetti`，与过关撒花同一套配色，只是原地炸一次）
- 📊 四个闯关游戏（连连看 / 消消乐 / Emoji 大师 / Emoji 排序）顶部卡片底部有本关进度条，操作区另一半显示本关盘面信息（连连看 / 消消乐：尺寸 · 种类 · 墙数，Emoji 大师：层数 · 种类，Emoji 排序：槽位 · 每槽层数 · 种类），并且只放「新游戏」按钮（点开的是这几个游戏共用的同一个二次确认弹窗 `shared/ConfirmDialog.vue`，确认后清记录、从第 1 关重来），失败时在结算浮层上「重玩本关」
- 🔹 各 emoji 游戏（对对碰 / 连连看 / 侦探 / 猎手 / 消消乐 / 大师 / 排序）的游戏区都带一层很淡的点阵底纹，牌消掉后不至于一片空白
- 🎨 这七个 emoji 游戏共用一套视觉参数：棋子/牌面圆角与描边、软阴影、牌背用各自在首页的图标、面板与统计条尺寸、按钮样式、结算浮层的间距与字号（浮层用 box-sizing: border-box，尺寸正好贴合棋盘）
- 🖐️ 首页卡片支持拖动排序，顺序记在本地；新增游戏自动接在已排序结果之后
- 🥚 彩蛋：在有成绩记录的游戏（点击 / 迷宫 / 对对碰 / 连连看 / 侦探 / 猎手 / 消消乐 / 数独 / 排序）中连点标题 5 次清除历史记录

## 技术栈

- Vue 3（Composition API + `<script setup>`）+ Vue Router
- Vite 5
- UnoCSS（attributify + icons：carbon / mdi）
- SCSS
- vite-plugin-pwa
- canvas-confetti

## 快速开始

```bash
yarn install
yarn dev       # 启动开发服务器
yarn build     # 构建到 dist/
yarn preview   # 本地预览构建产物
```

> 本目录的 `.yarnrc` 已将 registry 覆盖为 npm 官方源；若你的全局 yarn 指向内网镜像，无需修改即可正常安装。

## 目录结构

```
src/
├── App.vue          # 根组件 + 全局主题 CSS 变量（浅/深两套）
├── router.js        # hash 路由：/ /click /puzzle /guess /poker /three /2048 /snake /match /link /detective /hunter /crush /sudoku /master /sort /down
├── shared/          # 共享模块：i18n（多语言）、theme（主题）、games（游戏注册表）、emojis（emoji 池）
├── components/      # HomePage（首页）、TopHeader（标题栏）、HelpDialog（帮助弹窗）
└── games/           # 十六个游戏源码，每游戏一个目录
    ├── click/  puzzle/  guess/  poker/  three/  g2048/  snake/
    └── match/  link/  detective/  hunter/  crush/  sudoku/  master/  sort/  down/
scripts/             # 图标源文件（SVG + 512px PNG）
public/              # favicon 与 PWA 图标
```

各游戏的完整说明与实现细节见 [AGENTS.md](./AGENTS.md)；本合集由同级的四个独立游戏项目（`click-game/`、`guess-number/`、`poker/`、`puzzle-game/`）合并而来。

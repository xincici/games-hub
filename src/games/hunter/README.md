# 猎手

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：记住目标 emoji，从候选区全部找回。

记忆收集挑战：记住目标 emoji，翻面后从候选区把它们全部找回；顶部统计卡中间显示**当前第几关**；「新游戏」会先弹二次确认（确认后清记录、回第 1 关）。
找回的候选会**弹一下并扩散一圈绿光环**，选错候选会**当场抖一下并标红**（与 侦探同款）、扣一条命（右上角一行 ❤️，失去的那颗会先放大淡出再变成 🤍）。
观察时长随关卡放宽（3 秒起、第 3 关起每关 +0.4 秒，第 6 关 4.2 秒）。
每关开始时展示区的目标牌一律从**背面**翻到正面（候选区同时整体扣在背面，中途不会先闪一下新 emoji），记忆结束后候选区再整体从背面翻正让玩家作答。
右上角帮助旁可以**切换牌面**，点一下换一种、循环顺序是 emoji → 扑克牌 → 麻将牌 → emoji。
扑克牌直接复用扑克游戏的牌（2:3 长方形），所以目标更多、候选区更宽：最多 9 个目标 / 4×8；
麻将牌是 131:168 的竖牌（万 / 条 / 筒 / 字共 34 种）：**关卡曲线沿用 emoji 那套，格子则按麻将牌的真实比例排**（和扑克模式按 2:3 排格子同一个道理），卡片本身就是一张麻将牌。
玩法完全一样，三套牌面的关卡进度与当前局面**各自独立保存**，互不干扰。

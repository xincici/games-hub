# 雀圣

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：5×5 麻将滑牌，消完整副可赢的牌。

5×5 棋盘上铺着 14 张麻将牌，这 14 张**一定是一副能赢的牌**（4 组顺子/刻子 + 1 个将，每种牌一局最多 4 张）：朝上下左右**滑动**，所有牌沿该方向移动直到碰边或被别的牌挡住（和 2048 同款、**不合并**）；横排或竖排里**紧挨着**的牌若正好凑成一组（三张：三张相同或同花色三张连续）或一个将（两张对子），会被浅橙色高亮边框圈住，**点齐这一组的三张牌就消掉这一组、点满一对的两张就消掉这一对**（先闪烁再消失）；只有点满的两张是相同的牌、并且还能和旁边第三张凑成刻子时，才浮出一个只提供「消除这一对」的小提示（顺子点两张不弹提示，接着点第三张即可）。
一张牌同时属于多个可消组时，要依次点你想消的那一组（点过的牌会亮起并抬起）才消得掉（判牌与顺序无关，不需要把点数排好）。
**全部消完即过关**。
难度**全部体现在开局摆盘上**、**第 20 关到顶**（之后一直保持第 20 关难度）：初始摆盘里「已经摆好的组数」从 4 组降到 0 组 —— 越早的关卡越常一开局就有整组挨着（点掉就行），第 19 关起全散着放。
**滑动步数上限每关统一 30 步**（放宽了限制，不再逐关收紧），步数用完还没消完就失败。
**两种模式**（顶栏帮助图标旁的按钮切换，各自独立记录）：**老模式**滑动时所有牌一路滑到底（每关 30 步上限），**新模式**每次滑动所有牌只移动一格（每局 50 步上限），其它规则完全一样；发牌时会用束搜索求出解、再用真实规则复演确认，所以**每局一定解得开**。
操作区右侧是**⚡ 上帝模式**（左侧是「新游戏」；只要局面回到本关初始局就可用（一次都没动过、或把操作全部撤销回来））：点下去会把发牌时就求好的最优解逐步演示完 —— 滑动与消除都走真实动画（要消的那一组会先亮起来），下方面板不再显示步骤文字、只看棋盘，期间完全挡住点击与滑动，再点一下可停止；**开局一定可解**（发牌时就丢弃解不开的局面并重发）。
**游戏区下方有撤销 / 重做**（与点击游戏同一套卡片样式，步数会一起还原 —— 清错一组会把残局变成永远拆不完的死局，所以能回退很重要）。
开局从左上到右下逐张铺开，滑动有过渡动画。
牌面是从用户给的整副牌图里裁出来拼成的**一张雪碧图**（`src/shared/mahjong-tiles.webp`：7 列 × 5 行、每格 131×168，181KB，万 / 条 / 筒 / 字，与麻将英雄共用一份），不是 CSS 画的；开局与**恢复记录**都从左上到右下逐张铺开，滑动有过渡动画

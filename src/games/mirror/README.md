# Emoji 镜像

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：猜出被打乱后藏起来的 emoji 顺序。

猜顺序：展示区先亮出这一局的 4~8 个 emoji，**洗一下再逐张翻面藏起来**；下方游戏区是同样那些 emoji 的另一种排列，**开局保证一个位置都不对**（错排）。
点一张再点另一张把两张换位，两个区中间的提示区告诉你游戏区现在**有几个位置和展示区相同** —— 展示区的顺序要靠提示自己推。
每次交换后先显示 0.5 秒「计算中」再出结果；交换带位移动画、翻面用 3D 翻转。
**五档难度**（4 / 5 / 6 / 7 / 8 个，默认最低）：4 单排，**5 是上 2 下 3**，6 是 3+3，7 是**上 3 下 4**，8 是 4+4，两个区都居中、大小随屏幕自适应。
有计时器，**每种难度各自记录最佳时间**；全部对齐即过关（两区一起翻正 + 撒花），局中局面、计时与胜利状态都存档，重进接着来

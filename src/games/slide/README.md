# Emoji 滑行

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：棋盘腾挪消除，计时结束前清盘。

棋盘腾挪消除：整块棋盘上每种 emoji 都成对出现。
**点**一个——上下左右有同款就把这两个炸掉；周围没有同款时，棋盘上所有同款一起晃动告诉你它们在哪。
也可以**按住拖**：它会带着这个方向上**紧挨着它的那一段连续 emoji** 一起滑动（空格会断开，空格后面的不跟着走），能滑多远取决于前面有多少空格，所以先消掉几对、空出来的格子就是滑行的通道。
松手时看你按住的那个落在哪：紧挨同款就消掉这一对、其它 emoji 留在滑过去的位置；没有同款则整组弹回原位（棋盘一格都不会变）。
万一走到怎么挪都消不掉的地步，棋盘会自动重排剩下的 emoji（先只换种类，实在不行就把一对同款挪到同一行/同一列），保证重排后一定有得消——包括只剩最后一对、而且两张既不同行也不同列的情况。
目标是在计时结束前清空整个棋盘；关卡越高棋盘越大、种类越多、时间越紧，且是**线性**爬升：第 1 关 6×6 · 5 种 · 99 秒（每对 5.5 秒），第 15 关到顶 11×8 · 7 种 · 176 秒（每对 4 秒），之后每关限时再收 3 秒、160 秒保底。
**连击**：两次消除之间没有无效操作（滑动没消掉 / 点了但没同款都算）且间隔 < 2.5 秒就算连上，棋盘上方弹出「N 连击」并放一束小烟花（连得越高字越大、粒子越多），间隔超时或出现无效操作即中断。

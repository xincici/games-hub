## 实现

CrushGame.vue（emoji 消消乐 · 闯关制：限定步数内达到目标分过关。各因素随关卡线性爬升：面板 7×7→9×10、**种类 4→6**、步数 22→20、目标分 **1500→3000**、墙 0→8、冰块 0→8、炸弹 / 万能概率；第 30 关**结构**到顶（面板 / 种类 / 墙 / 特殊元素），且列 / 行 / 种类到顶时点刻意错开避免难度断崖；**第 30 关之后步数与目标分继续涨（每关 +1 步 / 目标分 +230 —— +1 步在 6 种盘面上约值 200 分，所以 +230 才让难度不会一关关变松）**，难度不会早早固定。顶部统计条底部有本关进度条（得分 / 目标分），操作区左侧显示本关盘面信息（列×行 · 种类 · 实际墙数，墙数为 0 时不显示），右侧只有「新游戏」（二次确认、清记录回第 1 关，无计时器），失败遮罩给「重玩本关」。💣 炸弹（相邻格被消除即引爆，炸掉周围 3×3、每格 12 分并震动棋盘、可链式引爆）、💎 万能元素（连线判定时可充当任意种类）、🧱 墙（不可交换 / 消除，但 emoji 下落时穿过）、❄️ **冰块**（FROZEN - kind 编码，冰下那种 emoji 一起存档）：**不参与连线、不能交换、也不随重力下落**（和墙一样被穿过），**相邻格（含斜角）被消除即解冻**——原地变回普通 emoji、保留 gem 身份只换值（是「化掉」不是换牌），化开后可能顺势凑出新的一组形成连锁。**顺序坑**：`applyThaw` 只化 `isFrozen` 的格子（被炸的冰同时在 `cleared` 与 `thawed` 里，无条件化回来会算出 `frozenKind(null)` = -100 的假冰＝「炸到的冰没碎」）。冰块**永远生成连通一片**（`placeIce` 四邻扩散），0 → 8 块随关卡爬升（`levelConfig().ice`：30 关到顶，之后每 2 关再 +1、14 块封顶，与墙 / 种类错开），只冻普通 emoji（落在炸弹 / 万能元素上时换成随机普通种类）；重洗只重排普通 emoji，冰与墙原位。渲染是牌上一层半透明冰蓝玻璃（`--ice-*` 五变量，浅 / 深两套）+ 雪花 + 冰下 emoji 轻微褪色；解冻时**冰层裂开 + 6 片冰蓝碎屑飞散**（`--ice-shard` 实心冰蓝，尺寸 / 距离按格子比例给；独立的 560ms 定时器回收，不被「落定清标记」抢跑截断）；炸弹与万能元素 0.95~1.05 呼吸缩放；开局 / 恢复逐格入场。**空闲提示**：6s 没操作就扫出所有能消的交换，取「消得最多」那一档随机挑一对（排除最近提示过的 3 对），让这两张牌同时起两种提示 —— `.gem.hinting .face` → `breathe 0.8s`（1 → 1.42 带 ±7° 摆动 → 0.66 → 1.08）、`.gem.hinting` → `hint-card 0.8s`（只动 background-color / border-color / box-shadow：暖黄底 `--hint-bg` + 品牌绿描边与光晕 `--hint-glow`，**不动位置**，免得和交换 / 下落的 left/top 过渡打架），`HINT_MS` 2600ms 后收起；任何点击 / 触摸立刻收起并重新起 6s 计时（发牌与连锁结算期间不提示、结算后不再提示）。**大消 / 连锁庆祝**：一轮消掉 4 个以上或连锁 ≥2 层时中央弹浮字（`niceCombo` / `niceBig` + 本次得分，两者同时达成分上下两行）、棋盘外圈播 `board-celebrate` 闪光（只动 box-shadow、不改变文档可滚动范围）、这批牌用 `.gem.matched.huge` → `pop-out-big`，并调 `shared/confetti.js` 的 `burstConfetti`。**恢复存档不走 `initLevel`，必须在 `onMounted` 里补一次 `pokeIdle()`**，否则「接着上次的局面玩」时永远不提示。**两条易踩的动画约束**：①`syncGems` 的输出顺序必须是「老 gem 保持原相对顺序 + 新 gem 追加末尾」，按格子顺序重排会让 keyed diff 去搬动 DOM 节点，而同父节点内被搬动的元素会丢掉正在跑的 left/top 过渡（下落变瞬移）；②`matched` / `blasting` 这两条消除动画的 CSS 规则必须写在 `fresh` / `falling` / `dealt` 之后（同权重靠后者胜出），并且 `resolveCascades` 在标记消除时先摘掉这些牌身上的 `fresh`/`fall`，否则连锁中刚落地（甚至刚生成）的牌只会沿用 drop-in / land-bounce、消除动画根本播不出来 + board.js（纯逻辑：参数化关卡曲线 levelConfig（第 30 关结构到顶、之后步数与目标分继续线性上涨）；**难度用离线模拟标定**：`findBestSwap` 挑最大三连当「稳定消的玩家」每关跑 100 局取中位。目标分线性上涨，但单步收益随种类下降（**实测约 590 → 285 → 200 分/步**），所以「目标分 / 中位分」从第 1 关 **0.12** 缓升到第 30 关 **0.74**，中段在第 9 / 第 21 关各上一个台阶（种类换档，刻意保留）；贪心玩家过关率 1~19 关 100%、第 21 关起 95 → 89 → 86 → 83 → **80%**（人类只有贪心玩家的 5~7 成水平，实际更难）。旧曲线 650→2200（过关率 97~100%）偏易，已上调。复现：`generateBoard` → 循环 `findBestSwap` 挑最大三连 → `resolveTurn` 结算、用完 `moves` 计分（无解先 `reshuffle`）。另含：生成（无现成三连且有解）+ 按种类扩展的连线判定（某个种类的连续块 = 连续的同种 emoji 或钻石，块长 ≥3 且块内真有该种 emoji 时整块消除 —— 钻石因此能跟着左右任一侧真正成组的那段走，两侧都不成组就不消；整块全是钻石不消）+ explode 链式爆炸 + 穿墙重力 + 计分（三连 60 / 每多消一个 +35、连锁每满一层 +30% 且最多翻倍、炸弹每格 12 —— 基础分给足，降低过关对连锁与炸弹的依赖）+ 离线校准用的 findBestSwap/resolveTurn）+ i18n.js（route /crush，key 前缀 __emoji_crush__）

## 存档（localStorage）

  - Emoji 消消乐：`__emoji_crush__*`（闯关进度 `__emoji_crush__level`=当前关卡，历史最高关卡 `__emoji_crush__best_1`（沿用「前缀+数字」以便连点标题清记录），局面存档 `__emoji_crush__state`（关卡、盘面（含墙/炸弹/万能元素的负值标记）、得分、剩余步数、胜负状态；**胜利与失败局面都保留**，退出重进仍是结算层：胜利由玩家点「下一关」，失败点「重玩本关」（只有「新游戏」才清记录；`loseLevel` 里不再 `removeState`，`restore` 也放行 OVER））；旧的 `__emoji_crush__difficulty`、`__emoji_crush__best_2/3` 已废弃）

# Emoji 消消乐

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：三消闯关，限定步数内达成目标分。

闯关制三消：限定步数内达到目标分过关（无计时器）；面板从 7×7 长到 9×10，emoji 种类从 4 种长到 6 种（步数 22 → 20、目标分 1500 → 3000、墙 0 → 8），带 💣 炸弹（相邻消除即引爆、炸掉周围 3×3 并震动棋盘）、💎 万能元素（可当任意 emoji 参与连线）与 🧱 不可消除的墙（emoji 可穿过下落）、❄️ **冰块**（冻住的 emoji 不能消除也不能交换，消掉相邻的格子即解冻（冰层会裂开、碎冰四散）；永远连成一片出现，随关卡从 0 块涨到 8 块（第 30 关），之后每 2 关再 +1、最多 14 块），操作区会显示本关墙数；第 30 关面板 / 种类 / 墙 / 特殊元素到顶，之后每关 **+1 步、目标分 +230** 继续线性加码，难度不会早早固定。
计分以基础消除为主（三连 60 分、每多消一个 +35；连锁每层 +30%、最多翻倍；炸弹每格 12 分），离线模拟（贪心挑最大三连）下第 30 关中位分约 3900 对目标 3000、过关率约 8 成（冰块因为邻格一消就化、对贪心玩家几乎无影响，对人则要花心思先化冰）；6 秒没有操作会提示一对可消除的 emoji（该交换的两个 emoji 大幅呼吸三下，牌面底色同时脉冲发光，每次换一对）；一轮消掉 4 个以上或连成连锁时庆祝：棋盘外圈闪光、中央弹出「连消 / 连锁 + 本次得分」并撒花（两者同时达成时两行文案上下分开显示），一轮 ≥4 个的那批牌还会爆得更大

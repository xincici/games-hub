# 单人麻将

把 14 张手牌凑成**能胡的牌型**：

- **四组三张 + 一对将**（三张相同的「刻子」，或者同花色连着的三张「顺子」），或者
- **七对子**（七个对子）。

## 怎么玩

1. **点一张手牌打出去** —— 牌会飞到下方出牌区，正面朝上摆着。
2. 打完之后**自动从牌墙摸一张**：新牌会先停在手牌**最右侧**，等你再打出一张，整副手牌就按顺序重新排好。
3. 牌墙里的牌是有限的（**剩余牌数**就显示在标题栏下方）。**摸完还没胡**，本局结束、当前连胜归零。
4. 胡了会先把你的手牌**排整齐**、每张牌**挨个跳一下**，然后才弹胜利提示并撒花，**当前连胜 +1**
   （最长连胜跟着刷新）。

手牌按 万 → 条 → 筒 → 字 排序；**每一局都缺一门**（这一局的万子/条子/筒子必有一个整场都不会出现，
按钮区左侧会写明缺的是哪一门），
「新游戏」按钮左边会写着「本局没有X」。

**出牌区**：你打出去的牌正面朝上排在这里（一行 14 张，最多三行）。

点「🎮 新游戏」会**清掉当前连胜、从头开始**（最长连胜作为记录保留）；当前连胜大于 0 时会先问一句
「开启新游戏会清除当前连胜并重新开始，确认吗？」。想带着连胜继续打，就点胜利提示里的「再来一局」。

**连胜越高越难**（有上限）：牌墙会变短、你需要的那几张牌会埋得更深 —— 连胜 0~1 时牌墙 40 张、
那两张牌基本在前 8 张内；连胜 10 以上牌墙只有 24 张、要埋到前 18 张里。

## 说明

- 牌墙一开始有 **40 张**（牌堆区把每一张都画出来，摸一张就少一张），去掉了发到你手上的 14 张；
  任何一张牌在一局里都不会超过 4 张。
- 每一局发出来的手牌都是**只差一步就听牌**的：先打掉那张「多余」的牌，你就听牌了，
  而你需要的那张牌一定在牌墙里 —— 剩下的就看你怎么打了。

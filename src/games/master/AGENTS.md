## 立体卡片（3D）

盘面 / 托盘 / 飞行中的卡片都是**立体的**：正面 + 底部一条厚度 + 落地阴影，像从正面偏下方斜着看过去
（和麻将英雄的牌同一套做法）。三处共用 `<style>` 顶部的 `@mixin card-3d($lip)`，
`$lip` 传厚度的尺寸表达式 —— 牌 `calc(var(--tile) * 0.07)`、托盘卡 `calc(var(--slot) * 0.07)`、
飞行卡 `var(--lip, 3px)`（它是 Teleport 到 body 的，拿不到页面上的变量，所以 `flyStyleOf()` 按飞行尺寸
写进行内样式的 `--lip`）。侧面色用 `color-mix(in srgb, var(--card-bg-color) 74%, #000)` 得到：
本作的卡面跟主题走，浅色是白 → 灰、深色是深灰 → 更深。被压住的卡（`.covered`）**保留厚度**，
`filter: brightness(0.5)` 会把阴影一起压暗，这样叠起来仍然是一摞有厚度的牌（原来那行 `box-shadow: none`
已删）。

**厚度要留出空间，而且要在卡所在的那一层留**（这个坑麻将英雄分册里记过详细版，这里说本作的具体做法）：

- 盘面：底部内边距用 `--board-pad-b = --board-pad + --lip`；同时把 `unit` **反解小一点**，
  让「14 格 + 内边距 + 厚度」的总高与加立体之前**完全一致**（`u = (14u₀ + 2r) / (14 + 2r)`，r = 0.07），
  否则小屏本来就在滚动的高度会再多出 5px。实测 320×568 加立体前后都是 46px 溢出、360×640 都是 19px、
  390×844 都是 0（这页在小屏本来就滚，是历史情况，不是这次引入的），牌只小约 1%。
- 托盘：卡片 `top: 8px`、高 `--slot`，底部那 7% 厚度落在托盘 8px 的内边距里，**托盘高度公式不用改**。
- 最下一排（y = 12 半格）实测：牌面底距盘面底 21.7px、连厚度 19.7px、连阴影 16.4px，都在盘面内；
  托盘卡连厚度距托盘底 4.9px（同样是那 8px 内边距在兜）。

### 落格交接不能闪（飞行卡 → 托盘卡）

**现象**：卡片飞进下方暂存区、落格的那一刻会闪一下（卡片先消失、再从透明淡回来）。
逐帧采样（`requestAnimationFrame` 里查 DOM 里有没有卡覆盖槽位中心，注意
`elementFromPoint` 会跳过 `pointer-events: none` 的 `.fly-card`，必须直接查 DOM）：

```
改动前： S S … F F F F F F  T~0.00 T~0.00 T~0.07 T~0.22 … T~1.00 T T …
改动后： S S … F F F F F F  T T T T T T …
```

**两个原因**：① `fly()` 里先 `flights.value = filter(...)`（飞行卡立刻从 DOM 消失）**之后**才
`tray.value.splice(...)` 插托盘卡，中间至少有一帧「两张都不在」；② 托盘卡带
`animation: card-pop 0.2s backwards`，而 `card-pop` 是 `opacity: 0 → 1`，所以即便插进去了，
它也会从透明重新淡入 —— 这一下淡入就是肉眼看到的闪烁。

**改法**：先插托盘卡并 `await nextTick()` 等它渲染出来，**再**撤飞行卡；同时给刚落格的卡打
`fresh` 标记跳过 `card-pop`（`.tray-card.fresh { animation: none }`）。普通入场 / 恢复存档的卡
仍照常播 `card-pop`。另外飞行卡在动画末尾会被缩放到与托盘卡同尺寸，而两者的厚度与阴影都是
按各自尺寸算的，所以交接那一刻是像素级对齐的 —— 这也是飞行卡要带 `card-3d` 的原因
（原来飞行卡用的是 `--shadow-float`，与托盘卡的 `--card-shadow` 不一致，交接时阴影会跳一下）。

**通用教训**：一个「临时元素」把位置交接给一个「常驻元素」时，永远要**先让接收方出现、再撤走来源**，
并且**跳过接收方的入场动画**（它已经在屏幕上了，再播一次入场就是闪）。

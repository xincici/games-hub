# Emoji 大师

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：羊了个羊式堆叠消除。

羊了个羊闯关玩法：点击未被遮挡的顶层卡片落入 7 格收集槽，凑齐 3 张相同 emoji 自动消除；被压住的卡片**一律不透明**（不按层数变透明，压得再深也只看得到从上层卡片边缘漏出来的那一角，想确认下面是什么就得先把它翻开），只靠变暗表示暂时不可点，游戏区是一张带底色的卡片；**卡片是立体的**（正面 + 底部一条厚度 + 落地阴影，像从正面偏下方斜着看过去，飞入暂存区后与飞行卡像素级对齐、交接不闪）；关卡越高层数与 emoji 种类越多（2 层 7 种 → 8 层 18 种，第 50 关到顶），同一种 emoji 可以出现多组（张数恒为 3 的倍数），无计时器、无洗牌，失败可重玩本关

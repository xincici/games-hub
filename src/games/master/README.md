# Emoji 大师

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：羊了个羊式堆叠消除。

羊了个羊闯关玩法：点击未被遮挡的顶层卡片落入 7 格收集槽，凑齐 3 张相同 emoji 自动消除；被压住的卡片**一律不透明**（不按层数变透明，压得再深也只看得到从上层卡片边缘漏出来的那一角，想确认下面是什么就得先把它翻开），只靠变暗表示暂时不可点，游戏区是一张带底色的卡片；**卡片是立体的**（正面 + 底部一条厚度 + 落地阴影，像从正面偏下方斜着看过去，飞入暂存区后与飞行卡像素级对齐、交接不闪）；关卡越高层数与种类越多（2 层 7 种 → 8 层 18 种，第 50 关到顶），同一种可以出现多组（张数恒为 3 的倍数），无计时器、无洗牌，失败可重玩本关。

**三种牌面模式**：点右上角（帮助按钮旁边）的图标即可在 **emoji → 扑克牌 → 麻将牌**之间循环切换。
扑克牌与麻将模式下**卡片本身就长成牌的形状**（扑克 2:3、麻将 131:168 的竖牌，不是方框里放一张小牌），托盘槽位也跟着变成牌形。
玩法完全一样，但麻将模式**更难一点**：牌面有 34 种可选、实际用到的种类更多（10~26 种），
而且「同一种牌出现 6 张」的情况比 emoji 模式少一半以上。**三种模式的关卡进度与当前局面各自独立保存**，
来回切换互不影响。

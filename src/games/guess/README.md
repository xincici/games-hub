# 1A2B（原猜数字）

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：8 次机会猜出 4 位数。

8 次机会猜一个不重复数字的 4 位数，根据 xAxB 提示逼近答案

**连胜记录**：赢下一局当前连胜 +1（最长连胜是历史最好成绩，只增不减）；猜满 8 次输掉或点「新游戏」都会
把当前连胜清零。统计条上是 `🏆 最长连胜` / `🔥 当前连胜`。

「新游戏」在**还没输**的时候会先弹二次确认（会清空当前连胜，最长连胜保留）；已经输了则直接重开。
退出再进来会接着上一局（包括已猜的历史和用时）。

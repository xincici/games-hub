# 麻将英雄

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：3×3 麻将消除，凑顺子 / 刻子。

3×3 棋盘上的麻将消除（标题栏帮助图标旁可切换**闯关 / 无尽**两种模式）：牌只有**一筒到九筒**九种，每种 4 张共 36 张的牌墙（所以允许重复，刻子要的就是三张一样），提示区只有手上这张和下一张。
凑满一整行 / 一整列 / 一整条对角线（共 8 条线，每条 3 张）凑成牌型即闪烁消除 —— **顺子**（三张点数连续）100 分、**刻子**（三张相同）200 分；一次落子在多条线上都成牌型时全部计分，并从第二组起每组再加 100（两组 +100、三组 +200）；**连续消除还有连击奖励，从第二连起每连一次多 50 分**（中间有一手没消掉就归零）。
**点已经有牌的格子会用手上这张把它替换掉**（原来那张弃掉、照样消耗一张手牌），所以棋盘放满不是死局，**只有牌用完了分数还不够才失败**；无尽模式牌墙无限、也没有结束条件，一直玩到你自己点「新游戏」。
牌面复用**雀圣那张雪碧图里的筒牌**（`src/shared/mahjong-tiles.webp`，与雀圣共用一份：7×5 格、每格 131×168；一筒三色大圆、二筒竖排、三筒斜排、四/五筒四角、六筒上二绿下四红、七筒上三绿斜排 + 下四红、八筒八点、九筒三行三列，红绿黑三色），每次得分会在棋盘中央弹出牌型名与得分，满 300 还会震动、闪光并撒花，过关 / 失败浮层等它露一下脸（0.5 秒）后出现。
闯关模式第 1 关 **20 张牌 / 400 分**，之后**每关 +1 张牌（逢 5 的整数关那一档 +2 张）**，过关分每关 +50

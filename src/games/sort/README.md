# Emoji 排序

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：水排序：把每个槽理成同一种水果。

水排序式闯关玩法（标题栏帮助图标旁可切换两种玩法）：槽里的水果只有最上面那张是正面朝上的；点一下槽位，它槽口那一摞同种水果会整摞抬到槽口上方、像牌堆一样叠起来（每张盖住下面那张约 85% 的面积，最上面那张完整可见；再点一次就放回去），点另一个槽位则先在上方的空白带里平移过去、再从目标槽正上方落进去；**如果抬起的那一摞只有一个槽放得下，它会直接自动搬过去落下、搬运途中目标槽的高亮也会一直亮着，不用再点第二下**（有多个目标时仍由你选）（目标装不下时只搬得下的那几张，剩下的落回原槽），落定之后下面那张才自动翻面。
难度由每种水果的张数 C 与种类 K 交替爬升，每 2~4 关抬一档，从 3 种×3 张涨到第 30 关的 6 种×8 张（48 张）；把每个槽都理成同一种水果、并让所有水果都翻成正面即过关；每一局的牌都先用求解器验证过有解才发出来，每走一步还会判一次——只有「还有水果扣着、却再也翻不开新牌了」或者「全翻开后已经怎么排都排不出来」才判失败（只要还翻得开就不会判负）。
**失败演出**：判负时先等刚翻开那张的翻面动画播完，停 0.5s，然后六个槽从左到右挨个把整摞水果抬起一格再落下（像整盘牌一起叹口气），全部落定才弹出失败浮层，这段演出期间不响应任何操作；失败后可以在结算浮层上「重玩本关」。
两种玩法共用这条曲线：**经典**每种水果刚好装满一槽，左右两侧各留 1 个空槽；**紧凑**只在最右侧留 1 个空槽，但每个槽开局都空出最上面一格当腾挪空间。
两种玩法的关卡进度与局面存档各自独立，「新游戏」只清当前玩法

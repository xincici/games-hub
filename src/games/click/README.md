# 关灯游戏

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：点灯把全盘灯都熄灭（灯有三档：灭 / 全亮 / 半亮）。

每一格是一盏灯，三档亮度循环：**灭 → 全亮 → 半亮 → 灭**。点一盏灯，它和上下左右的邻灯都变到下一档（全亮变半亮、半亮熄灭、熄灭的直接全亮），在限定步数内把所有灯熄灭即获胜；另有**⚡ 上帝模式**（刚开局、还没手动点过时可用）自动完成最优解，**播放中再点一下按钮即可暂停 —— 暂停就是把操作权交回给你**（遮罩撤掉、可以接着手动点或撤销），把所有操作撤销回初始局后可以再点它重跑

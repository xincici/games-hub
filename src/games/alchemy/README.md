# 扑克炼金术

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：4×4 扑克炼金 / 3×3 炸金花，两种关卡模式，凑牌型消线得分。

标题栏帮助图标旁可以切换两种模式，**两种模式的关卡、进度和局面各自独立保存**：

- **🃏 炼金闯关（4×4）**：把手上的牌放进空格（也可以拖进去），凑满一整行 / 一整列 / 一整条对角线（共 10 条线）、且这 4 张能组成牌型时计分并消除。一次落子同时凑成多条线时只算分数最高的那条，只有最高分并列才一起消除并累加。
  - 牌型：四条 / 同花顺 1000、三条 500、顺子 300、同花 200、两对 100、一对 50。
  - Joker 是万能牌，但受颜色限制：黑色只能当 ♠/♣、红色只能当 ♥/♦；棋盘上不会出现两张一模一样的牌。
- **🎴 炸金花闯关（3×3）**：3×3 棋盘、8 条线（3 行 + 3 列 + 2 条对角线），每线 3 张。点空格放牌，**点已经有牌的格子可以替换掉它**（同样消耗一张手牌），所以棋盘放满也能继续玩。
  - 牌型：豹子 1000、同花顺 800、同花 500、顺子 400、一对 200；散牌不计分、不消除。
  - **多消加分**：一次落子同时凑成多组时全部计分，并从第 2 组起每组再加 200。
  - **连击加分**：连续每次消除算一连；从第 2 连起每连再加 100，中间有一手没消掉就归零。
  - A 可以当 1（A23），也可以接在 K 后面（QKA）。

两种模式都是**关卡制**：第 1 关 18 张牌 / 1200 分，之后每关 +1 张牌、过关分 +100，逢 5 的整数关那一档多 +2 张牌（牌数封顶 52）。在牌用完前达到目标分即过关；牌用完还没达标就失败。新游戏会清掉**当前模式**的关卡与最高关卡记录，另一种模式不受影响。

# 扑克炼金术

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：4×4 扑克炼金，凑牌型消线得分。

4×4 棋盘上的扑克炼金（标题栏帮助图标旁可切换**闯关 / 无尽**两种模式）：手里一次只有一张牌、面板上还能看到接下来的两张（逐张小一号），点空格放入或把牌拖进空格 —— **点空白时那张牌会从手牌位置飞到目标格**，拖拽则跟手。
凑满一整行 / 一整列 / 一整条对角线（共 10 条线）且这 4 张能组成牌型时，该线**先闪烁两下再整条消失**并计分 —— 四条 1000、同花顺 1000、三条 500、顺子 300、同花 200、两对 100、一对 50（凑不出牌型的线不消、留在盘上占格）。
**一次落子同时凑成横 / 竖 / 斜多条线时只算分数最高的那条**，只有最高分并列才一起消除并累加分数，分数低的那几条原样留在盘上。
牌堆里混有 **Joker**（按德州扑克的规矩渲染：黑 Joker 当 ♠、红 Joker 当 ♥）：**黑色的只能当 ♠/♣、红色的只能当 ♥/♦**，所以一黑一红两张永远凑不出同花；两种 Joker 各只有一张，**棋盘上也不会出现两张一模一样的牌**（发牌器按 52 张的牌靴抽、避开场上已有的牌）。
**每次得分**都会在棋盘中央弹出「牌型名 + 本次得分」（照消消乐那一套，按分数分档放大），得分满 **300** 还会让棋盘震动、外圈闪光并撒花（低于 300 只有浮字）；过关 / 失败浮层会等这条提示露一下脸（0.5 秒）后再出现，过关本身用共用的那份大撒花。
闯关模式第 1 关 24 张牌 / 800 分，每关 +1 张牌、过关分 +50、每 10 的倍数关再多 +100，在牌堆用完前达到目标分过关，无尽模式牌堆无限、直到 16 格全部放满才结束（「新游戏」只清已用牌数与当前得分、**保留最高分**），统计条随模式变化 —— 闯关四格「**关卡 / 剩余 / 得分 / 目标**」、无尽三格「**最高分 / 已用牌数 / 得分**」，两种模式各自独立记录  开局与**恢复记录**都从左上到右下逐张铺开（波浪），落子 / 消除各有动画。

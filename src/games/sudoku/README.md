# 数独

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：唯一解数独，填错扣命。

唯一解挖洞生成，填错即标红并扣 ❤️ 生命（三档难度各带 1 / 2 / 3 颗 ❤️，扣掉最后一颗的那次即失败，也就是简单错一次、中等两次、困难三次），支持笔记候选（手动逐个标记）与**候选**一键填空（激活后点空白格，自动填入该格所有可用候选 = 排除同行、同列、同宫后剩下的数；两者互斥）；右上角还有**候选按钮行为开关**：开启后按一下「候选」就直接把所有空白格一次填满；点盘面上任意一个数字，会同时高亮所有同数字的格子和其它空格里相同的候选数字（候选数字直接给**底色块**，同数字格、同行列宫格、选中格是三档由浅到深的高亮，被高亮的格子里数字统一用实心字色，避免绿压绿看不清）；**填对一个数字后，会把它从同行、同列、同宫其它空格的候选里自动划掉**（填错则不动）。

## 实现

SudokuGame.vue（数独：唯一解挖洞生成、填错即标红、爱心生命（难度 1~3 = 初始 ❤️ 1~3，用 `shared/Hearts.vue`；`checkMistake` 扣掉**最后一颗**心的那次就直接 `lose()`，所以简单错一次、中等两次、困难三次即失败）、笔记候选（手动）、**「候选」一键填空**（激活后点空白格即写入该格所有可用候选 = 排除行 / 列 / 宫；与笔记互斥）；顶栏帮助旁还有一个开关（`__sudoku_game__cand_all`：关 = 逐个填、开 = **按一下候选就填满全盘空格**，开启时把逐个填的模式收掉；图标 `i-mdi-gesture-tap` ↔ `i-mdi-select-all`）。点盘面上的数字会高亮同数字的格子与其它空格里相同的候选；**正确填入一个数字后会把它从同行 / 列 / 宫其它空格的候选里划掉**（`pruneNotes`，只在该格填对时执行并立刻落档；填错不清 —— 那个数字其实没落位）。**三档高亮**用 App.vue 里数独专属的 `--sudoku-hl-bg`（同行 / 列 / 宫，最淡）/ `--sudoku-same-bg`（同数字）/ `--sudoku-sel-bg`（选中格，最深 + 主色描边），**不能复用 `--key-bg` / `--enter-bg`**（那两个还被数字键盘与工具按钮共用）；候选数字的高亮是**底色块**（`--primary-bg` 底 + 白字），**凡是被高亮的格子（`.hl` / `.same` / `.sel`）数字都用 `--text-color` 实心字** —— 底色加深后主色绿压在上面会发闷，同数字格在深色主题下原来只有 **1.14:1**（几乎看不出，玩家反馈「数字颜色和背景色很接近」）；现在浅色主题选中 / 同数字 / 同行列宫是 5.96 / 6.82 / 7.46:1、深色 3.33 / 4.82 / 6.62:1，候选数字底色块 4.92:1（对白格三档底色 1.47 / 1.61 / 1.84）。开局 / 恢复时格子与数字逐格入场。**两个坑**：①笔记按 `1 << d` 存（d = 1..9），数字 9 落在 bit 9 = 512，还原存档的掩码必须至少 `(1 << 10) - 1` —— 原来写 `& 511` 会把 9 的笔记整位抹掉（表现为「重进后只剩 9 的格子笔记整格消失」），现在用 `NOTES_MASK` 常量；②**行高跳动**：网格轨道必须写 `minmax(0, 1fr)`（`1fr` = `minmax(auto, 1fr)`，内容比轨道高就会把那一行顶大、其余行压小），高亮候选的色块也不能用 `line-height` 撑高（改成 `height: 100%` + flex 居中撑满自己那格）—— 否则点一个已填数字、让空格里的同数字候选高亮时整盘行高会跳（实测 39.33 → 38.78px；修复后点击前后行高与棋盘尺寸完全一致）+ sudoku.js（纯逻辑）+ i18n.js（route /sudoku，key 前缀 __sudoku_game__）

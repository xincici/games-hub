# 麻将传奇

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：条牌 + 少量字牌 + 极少量花牌（万能牌），升行顶出即结束。

8 行 × 7 列的游戏区（标题栏帮助图标旁无开关）：牌是**条牌 + 少量字牌 + 极少量花牌**：字牌（東南西北中發白）**平均每 14 张牌才出一张**，
**只能靠刻子 / 杠消除、凑不出顺子**；花牌（梅兰菊竹春夏秋冬）**不到 10%**（约每 12.5 张一张），
是**万能牌** —— 判组时可以当任意一张牌，比如「花 + 5条 + 5条」算刻子、「花 + 7条 + 9条」算 7/8/9 顺子；开局底部先摆**两行**牌、且这两行保证没有任何可消的组合（**开局与恢复记录都从左上角到右下角逐张波浪式铺开**），之后随机的一行**条牌**从底部升起，点空格把手上的牌落到那一列（它会往下掉、落在已有牌上），点已有的牌就用手上这张替换掉它（旧牌弃掉）；**右上角可以切换条牌 / 筒牌的牌面展示**（纯展示，规则不变）；候选区显示当前牌与后面两张（与麻将英雄同一套样式）。
操作之后检测**紧挨着**的牌：三张连续（顺子）100 分、三张相同（刻子）200 分、四张相同（杠）300 分，一次消多组从第二组起每组再加 100。
**这次操作消掉了牌就不升行**，没消掉则底部升一行随机新牌并把整盘往上顶一格（新行本身也可能直接消除计分）；牌不会悬空，消除后悬着的牌下落，下落又消除算**连击**、每连额外 +100。
有牌升到最顶行就是最后机会：再升一次行就会被顶出棋盘，游戏结束（单局制、只记最高分）

# 24 点

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：用 4 个数字和加减乘除凑出 24。

每局给出 **4 个 1~9 的数字**（可以重复），它们一定凑得出 24。把 **4 个数字各用一次**，配合
加、减、乘、除和括号，组成一个结果正好等于 **24** 的算式即过关。

**怎么操作**：点下方的数字、运算符或括号，把它加进算式；点错了用「⌫ 退格」撤回最后一步。
数字的先后顺序由你决定，括号也可以用（最多三层）。用过的数字会置灰，当前不能加的也会置灰 ——
比如没有未闭合的左括号时右括号点不了，运算符后面也不能直接跟运算符。

按钮区最左侧会显示**当前这道题的难度评分（1~100）** —— 由这道题本身算出来：解越少、必须用分数、
每个解都要除法，分就越高；纯加减就能成、四个数字都一样、数字里有 1，分就低。

**难度**：每过一关难度都会递增 —— 有的题解很多（随手一试就成），有的题**只有一个解**、而且必须用分数
（例如 3 3 8 8 要写成 `8 ÷ (3 - 8 ÷ 3)`）才凑得出来。

**胜负与记录**：4 个数字全部用上、算式正好等于 24 即过关，**当前连胜 +1**（同时刷新最长连胜）。
点「💡 查看答案」算**放弃**：会告诉你一个正确答案，并把**当前连胜清零**（最长连胜保留）。
下一局点「🎮 新游戏」；赢了以后浮层上直接点「下一关」。

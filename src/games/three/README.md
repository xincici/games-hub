# Threes

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：1 + 2 = 3 的合成消除。

1 + 2 = 3 的经典合成：滑动合并相同数字，牌堆预告下一张牌；新牌固定从「滑动来源侧」边缘补进，盘面上 1 与 2 的个数差不超过 4。
在页面任意位置（不只是棋盘上）按住拖动都能滑，滑动是**跟手**的：手指按住拖动时，这一步会动的牌实时跟着位移（不足一格时正好压在目标牌上，形成重叠覆盖的手感）。
盖到目标牌一半以上再松手才合并，不到一半松手就弹回原格；盖到 95% 时不等松手就直接合并

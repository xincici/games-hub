# Emoji 下坠

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：反应街机：让顶层 emoji 对上同款炸一排。

反应类街机玩法：8 行 × 6 列的棋盘上，整排 emoji 从底部不断升起、把上面的排往上顶；你控制骑在整摞最上方的那一个 emoji，点任意一列它就**滑过去**（带滑动动画）——停在「顶层这一列的 emoji 跟自己相同」的位置，那**一整排就炸开消失**，你的 emoji 落到下一排上方，消一排得一分。
每一排都保证 5 种齐全，所以目标永远存在，比的就是在牌堆顶上来之前找到它；每消掉一排手里的 emoji 都有机会换一种——**第一次就有 25% 概率换，连续没换的排数越多越容易换，平均约 3.4 排换一次**（换来的一定是当前顶排里有的、且跟原来不同），每消一排上升速度还会再快一点，**到基础速度的 3 倍（1.05 行/秒）就封顶、之后不再加快**，emoji 被顶到棋盘顶部即失败。
操作区是「计时|新游戏|**暂停**」：可以主动暂停，切后台或离开界面也会**自动暂停**，重进时停在暂停态由你自己点「继续」，而点继续后会先在盘面上**倒数 3 2 1** 再恢复（贪吃蛇同样如此）。
局中局面与失败结算都存档，结算层上点「新游戏」重开

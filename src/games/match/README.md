# 对对碰

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：记忆翻牌闯关，限时清空全盘。

记忆翻牌**闯关**：每关先全体亮牌观察 4~14 秒（牌越多越久），然后翻面并开始限时倒计时（**观察与倒计时就显示在「新游戏」左边**），限时内清空全部牌过关；时间到则失败，**并把没消掉的牌全部翻到正面**摊牌。
关卡越高棋盘越大 —— emoji 与麻将 `2×3` 一路到 `6×8`、扑克 `2×3` 到 `6×7`（第 11 关封顶、关数无限），限时按「对数 × 每对 4~5.2 秒 + 4 秒」给；连续配对不翻错会累计**连击**并放小烟花。
右上角帮助旁的图标可以**循环切换三种牌面**：emoji → 扑克牌（2:3 长方形牌，直接复用扑克游戏的牌面）→ 麻将牌（万 / 条 / 筒 / 字，**关卡曲线与限时完全沿用 emoji**，只是牌面换成一整张竖着的麻将牌），再点一下回到 emoji。三套牌面的当前关卡与最高关卡**各自独立保存**；**只有分出胜负的结算会被记住**（重进或切牌面都停在结算浮层，自己点「下一关 / 重玩本关」）；一关还没打完就退出或切牌面，则**重开本关**，「新游戏」二次确认后只把当前牌面从第 1 关重开

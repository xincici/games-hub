# Emoji 连连看

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：连连看闯关，限定时间内清盘。

闯关制连连看：限定时间内清空全盘过关；列数 6→10、行数 6→12、emoji 种类、牌数、墙数（0→18）与限时共同决定难度，第 30 关到顶但关数无限；同一种 emoji 可出现多对。
**连击**：两次消除之间没有无效点击、且间隔在 2.5 秒内就累积连击，棋盘上方弹出「N 连击」并放一束快速烟花（连得越高字越大、烟花越大）；间隔超过 2.5 秒，或点到的牌没被消掉（emoji 不同 / 连线不通 / 取消选择），连击中断

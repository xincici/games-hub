# Emoji 侦探

> 玩家向的玩法简介。**开发向的说明（实现、存档 key、踩过的坑）在同目录的 [`AGENTS.md`](AGENTS.md)。**
>
> 一句话：记住牌面，找出被偷换的那张。

找茬记忆挑战：记住一组牌，翻面后找出被偷换的那一个，关卡逐步加难；顶部统计卡中间显示**当前第几关**；「新游戏」会先弹二次确认（确认后清记录、回第 1 关）。
**答对之后先停留 0.5 秒**（答对的牌当场亮绿并弹一下、扩散一圈光环），再弹过关浮层；**扣掉最后一颗心时不立刻铺失败遮罩**：先等点错那张的抖动放完，再在**被偷换的那张上盖一个歪的「✓ 正确」章**（像盖章一样落下来），随后这张牌震一下，最后才出失败遮罩与结算（答错的那几张仍标红）。
整个过程约 1.5 秒，让玩家看清答案是哪张；停留期间不能操作。
答错一次扣一条命，而且**点错的牌会红色标记、不能再点**（同一张最多只扣一颗心）（右上角一行 ❤️，失去的那颗会先放大淡出再变成 🤍）。
右上角帮助旁可以**切换牌面**：emoji ↔ 扑克牌（牌面直接复用扑克游戏的牌，长方形 2:3，所以排列按列多行少来适应宽高比）。
玩法两套完全一样，但扑克牌有花色 + 点数两层线索更好记，所以牌数更多（1×4 → 4×7 共十关，emoji 是 1×3 → 4×5 共九关）；两种牌面的关卡进度、最高关卡与当前局面**各自独立存档**，切回来接着上次继续

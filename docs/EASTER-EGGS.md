# 彩蛋与「不许写进帮助」的东西（`docs/EASTER-EGGS.md`）

这个项目有一条硬规矩：**帮助文案只讲玩法**（规则、分数、过关/失败条件），
**实现细节和彩蛋一律不写**。玩家该从帮助里学会怎么玩，彩蛋该自己发现。

## 现有的彩蛋

| 彩蛋 | 触发 | 实现位置 | 注意 |
| --- | --- | --- | --- |
| 清空全部记录 | 首页/游戏标题**连点 5 次** | `TopHeader.vue`（配合注册表的 `recordsPrefix` + 难度范围） | 顶部加新 key 时别忘了注册表里的前缀 |
| Emoji 镜像：偷看牌面 | 长按「⏱ 用时」那一格 **1.5 秒**，松手收起 | `mirror/MirrorGame.vue` 的 `PEEK_MS` / `peeking` | 只改一个独立标记，**不写存档**；换局/恢复/卸载要复位 |
| 「建设中」占位卡（当前没有启用） | — | `HomePage.vue` 的 `wip` 机制 | 恢复时照根 AGENTS 的说明加 registry 条目 |

## 加一个新彩蛋时的规矩

1. **不进帮助**：`help1..helpN` 里不许出现它的字眼（自检脚本会核对 `en` 段没有中文，
   但「有没有偷偷写进帮助」要靠人看 —— 加完自己读一遍）。
2. **不动存档、不动游戏状态**：彩蛋只允许改一个**独立的瞬时标记**（像 `peeking`），
   否则会污染进度、破坏「可解/可恢复」的保证。
3. **可撤销**：松手 / 换局 / 恢复存档 / 组件卸载都要复位，别留残留状态类。
4. **不改变难度与判定**：彩蛋不能让玩家误获胜或误失败。
5. **记进本文件**：触发方式、实现位置、注意事项三栏。
